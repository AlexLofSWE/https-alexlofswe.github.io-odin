Open Odin

Odin runs inside Claude — it takes about 30 seconds to get started.

  1. Download the file using the button below — it's a single HTML file called odin-qad-lead-finder.html
  2. Go to claude.ai and sign in (free account works; Pro is faster for large searches)
  3. Start a new conversation — click the ✏️ new chat button
  4. Attach the file using the paperclip icon in the message box
  5. Type "Open this as an artifact" and press Enter
  6. Odin opens — you should see "Connected. Ready to find leads." in green
